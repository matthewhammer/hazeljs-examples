Hazel activities

Small apps whose rules are written in Hazel, a typed functional language with a live editor, and run in the page by hazeljs, each shown beside the program it runs. Each works on a phone, and with no connection once opened.

How each one works

The page passes the Hazel program random numbers, a birth's time and place, or a move, and draws what it answers, as Messed Up Dress Up's scripts and a Petri net simulator do.
