Ancient oracles, in Hazel

Ancient oracles whose rules are written in Hazel, a typed functional language with a live editor, and run in the page by hazeljs.

I Ching

The Book of Changes: six lines cast by coins or yarrow

Tarot

78 cards, dealt into a spread and turned one by one

How each one works

The page passes the Hazel program random numbers and draws what it answers, as Messed Up Dress Up's scripts and a Petri net simulator do.
