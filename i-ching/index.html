I Ching, cast in Hazel

Hazel activities › ancient oracles · source on GitHub · hazeljs on npm

Ask a question, then cast six lines, one at a time, from the bottom up: by three coins, or by dividing the yarrow stalks. Each line is cast by a Hazel program, shown beside the reading as text, or in Hazel's own editor at the press of a button; the page only passes it random numbers and draws what comes back. Change the program and the page builds it again. While it has an error or a hole, the page's own JavaScript casts instead, and each line says which did.
