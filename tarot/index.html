Tarot, dealt in Hazel

the ancient oracles · source on GitHub · hazeljs on npm

Ask a question, choose a spread, and deal: the cards land face down, each in its place. Turn them over one at a time. The deck, the shuffle and the spreads are a Hazel program, shown beside the table in Hazel's own editor; the page passes it random numbers and lays out what it deals. While the program has an error or a hole, the page's own JavaScript deals instead, and the table says which did.
